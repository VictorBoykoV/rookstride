# Rook's installation workshop

Fourteen original vector illustrations accompany actual installation checkpoints.
They retain the revision2 head, red body, charcoal scarf and cream satchel. The
props describe the current job; they never replace progress text or certify a
working phone connection. All artwork is GPL-3.0-or-later, as marked in each SVG.

| Key | Rook's task |
| --- | --- |
| connect | Join two cables |
| inspect | Examine a server with a magnifying glass |
| prepare | Read the construction plans |
| adblock | Turn away unwanted banners with a shield |
| configure | Set the controls |
| start | Press the power switch |
| verify | Check the complete route |
| send | Send the installation plans |
| monitor | Watch an activity chart |
| exit | Build the far station |
| bridge-exit | Anchor the far end of the bridge |
| bridge-entry | Secure the near crossing |
| forward | Open the gate |
| health | Read the final health report |

`InstallationProgress.illustration()` maps stable recipe/checkpoint IDs to these
keys. Each checkpoint within a recipe has a distinct picture. Paused/failed jobs
use the patient helper; completion uses the existing celebration. The generator
`scripts/prepare-rook-poses.py` converts these sources to Android drawables.
Do not edit generated drawables independently.

The small installation image rocks gently only while a stage is running and
Android animations are enabled. It is decorative, with the real stage written
beside it. No sound, flashing, new permission or downloaded artwork is required.
These app assets do not change the website or story reader.
