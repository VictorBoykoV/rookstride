Help

Get started

  • Set up a VPN installs on your own server. For a single-server VPN, the app checks Ubuntu 22.04 or newer and the components it needs. Choose a protocol, enter the server address and administrator password, then install. You can add more protocols to that server later.
  • Import a VPN connects using a profile someone shared with you. You do not need administrator access.
  • Manage a server adds a server with SSH administrator access and checks its existing Rookstride VPNs.

Rookstride remembers the server’s first SSH identity before sending your password. If that identity changes, sign-in stops. Check a server replacement or changed keys with your provider before resetting its saved identity.

Find your server and connection

The active or last-used VPN appears at the top of VPNs. Use its Connect or Disconnect button. Tap a server card to reveal installed protocols. Each has its own connection button; tap the protocol name to open its controls. The small protocol settings cog also opens its controls. Use the star there to add it to the swipeable quick-connection cards.

The settings cog, beside the server name, opens server controls: rename, refresh, administrator access and removal of all VPN setups. Hold a server to move it, or swipe left to reveal Delete. A normal server check is reused for 30 minutes; Refresh checks immediately.

Inside a connection, use VPN users, Logs, Usage and Ad blocking. Usage updates when opened and every five minutes while visible. Ad blocking is shared by native VPNs on that server; IKEv2 has its own filter. Double VPN manages filtering on the exit server.

Connect inside Rookstride

IKEv2, AmneziaWG 3.1, VLESS / REALITY (TCP), VLESS XHTTP / REALITY, OpenVPN, Hysteria 2, Outline / WSS, Shadowsocks / WSS, TrustTunnel and NaïveProxy all connect inside Rookstride. Only one phone VPN is active at a time.

Share a connection

Open VPN users → Add new user. Once the user is created, Share connection opens automatically. Share a file or text, copy the connection, or save a file. If retrieval fails, Retry sharing loads the existing account’s connection; it does not create another user.

AmneziaWG uses native 3.1 .conf; OpenVPN uses .ovpn; VLESS uses a vless:// link; IKEv2 uses .sswan. The other methods use Rookstride .rookvpn profiles. A newly created IKEv2 user’s shared profile includes the chosen VPN password. A profile shared later may need that password separately. Share only with someone you trust.

Split, Journal and Settings

Split chooses which apps use your VPN. Search for an app by name or find its icon. Changes apply when you reconnect. Apps outside the VPN use your normal connection; Android’s block-without-VPN option may block them instead.

Journal is a placeholder for Rook’s future adventures and news. No content server is configured yet, so it makes no requests. Comics are no longer bundled in the app.

Settings contains app preferences, saved administrator access, Journal storage, Help & FAQ and licenses. Activity is in the header bell. Administrator passwords are encrypted on this phone by default. They are separate from VPN-user passwords.

During setup

The progress screen shows the real installation stages, Rook’s stage illustrations and elapsed time. Time remaining is an estimate. Installation continues when you change tabs or leave the screen; use View progress to return. Check and resume recovers interrupted tracking. Abandon setup dismisses failed tracking; it does not cancel remote jobs or remove server software.

Double VPN

Double VPN, also called two-hop VPN, uses two different servers. Choose a phone protocol and the connection between servers, provide each server’s access, then review. The app shows available combinations and tests the exit before allowing traffic. New setups assess each server independently for Ubuntu 22.04 or newer; the versions may differ. Saved legacy IKEv2 → AWG setups retain their Ubuntu 24.04 installer until replaced with a new Double VPN. Existing Rookstride setups can be removed through the reviewed preparation flow.

Remove VPNs or start again

Uninstall this protocol removes its recognized setup, accounts and profiles. Remove all VPN setups removes all recognized Rookstride VPNs, their keys and filtering data. Both keep Ubuntu, SSH, downloaded packages and unrelated applications. Review the removal summary before confirming.

A compatible full virtual machine can use Wipe server & reinstall Ubuntu with its own erase confirmation. Unsupported layouts need your hosting provider’s rebuild feature. After a provider rebuild, verify the new server identity and update saved administrator details.

Connection problems

Installation and a working phone connection are separate checks. Open Logs inside the connection. The web check sends small HTTPS requests to example.com and Cloudflare through the VPN. UnknownHostException means a website name could not be resolved through the VPN. The app keeps the VPN on after an inconclusive check; try a website, reconnect or use Check web access again. Android Private DNS can affect DNS access.

SSH access alone does not prove that a VPN protocol can reach the server. Try another installed protocol when one cannot connect.

Play Protect

A directly downloaded test app can be unknown to Google Play Protect. Let Google scan it using Android’s action. Keep Play Protect enabled and report a harmful-app warning before continuing.

Server management and starting again

Administrator commands use encrypted SSH separately from your VPN connection. Another VPN app must allow Rookstride to reach the server; its lockdown settings cannot be overridden. Double VPN can automatically use whichever server answers as an encrypted SSH relay. Both server identities are checked.

Remove VPN setups removes reviewed Rookstride components and keeps Ubuntu and unrelated applications. Wipe server & reinstall Ubuntu replaces the system disk on compatible full virtual machines. It has a separate erase confirmation and verifies the planned new SSH identity before reporting success. Other layouts need the hosting provider’s rebuild tools. Remove server from this phone only removes the local record.

Generated VPN passwords have 15 random characters. Short manual choices show a warning you can accept; longer passphrases are allowed up to 127 UTF-8 bytes. Empty passwords and control characters are not supported.

Ubuntu 22.04 and newer are assessed without an upper version limit. A prerequisite check does not certify a future release: package, kernel and security changes may need fixes. Prefer a tested LTS. The OS reinstall selector has a separate reviewed image list.
