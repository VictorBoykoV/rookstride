Rookstride helps you install a private VPN on a VPS you rent, manage access, and connect from this phone. Meet Rook, our little red navigator.

Before your first gateway

  1. Rent a fresh Ubuntu 24.04 VPS with a public IPv4 address. A small server can serve modest use; throughput depends on its CPU and network.
  2. Obtain its SSH address, port and administrator password or private key. The administrator must be root or have passwordless sudo.
  3. Keep Wi-Fi or mobile data available. An existing VPN is not needed, but the phone must reach SSH and the VPS must reach Ubuntu package repositories.
  4. Add a gateway in the app and verify the SSH fingerprint against your provider's console if available.
  5. Tap Install gateway. Choose a VPN login and a strong password. The administrator password and VPN password serve different purposes.

Installation is for a fresh VPS. Rookstride refuses to overwrite an existing VPN or DNS configuration. A server configured with our supported gateway template can be enrolled using Manage existing.

Two-server gateway · experimental

Choose Add a two-server gateway and provide separate SSH details for two fresh Ubuntu 24.04 machines. Verify both SSH identities. This version supports one pair recipe: your phone connects with IKEv2 to the entry; the entry sends client traffic through AmneziaWG 3.1 to the exit. AdGuard Home and Unbound run on the exit.

The app prepares the exit, installs a blocked entry, links the nodes, verifies a recent bridge handshake, exit IPv4 and DNS, then activates forwarding. Failed steps keep forwarding closed. Reopen the saved pair and choose Resume; if matching kernel headers require a reboot, the app offers a controlled reboot and resumes the owned job afterward. Pause gateway blocks client forwarding without restoring a direct entry route.

One machine cannot be both roles. Two local virtual machines can exercise the installer but do not establish reliability between independent providers. A real deployment needs two VPSs. Pair upgrades and arbitrary imports remain unsupported. Use Reset both VPN nodes, review the owned paths and type DELETE PAIR. The app closes the entry before removing exit data and preserves Ubuntu and SSH. Then use Swap entry and exit or reinstall. A complete operating-system rebuild belongs in the provider panel. Other protocol recipes remain research proposals.

When one SSH endpoint cannot be reached

In the pair’s Advanced options, choose Manage entry SSH through exit or Manage exit SSH through entry. The app opens an encrypted SSH route through the other server and still verifies both host keys before their credentials. No extra server service is installed; the other server must allow SSH forwarding. This changes administration only. Your phone still connects directly to the entry over IKEv2.

What gets installed?

StrongSwan provides IKEv2/IPsec with username/password authentication. AdGuard Home filters DNS names for ads and trackers. Unbound resolves DNS on the VPS. Firewall settings route IPv4 through your gateway. IPv6 Internet traffic is blocked in this version, and DNS does not offer IPv6 destinations.

The management helper accepts specific actions through SSH. Optional accounting reads existing VPN counters and saves usage summaries on the VPS. Its management interface is local to the server.

Installation and interruptions

The installation runs as a service on the VPS. You can close the app or lose the phone's connection and check the saved job later. A VPS reboot or failed package installation can leave a partial installation; the app reports this rather than rerunning over it. Inspect the root-only installation log at /var/lib/rookstride/jobs/JOB/install.log. Use a fresh VPS if recovery would risk other services.

Connect on this phone

Download a profile for your login using Use on this phone, enter the VPN password, then tap Connect. Android will ask for VPN permission. The embedded VPN client is based on strongSwan. Profiles use a 1280 MTU and block IPv4 and IPv6 traffic outside the negotiated tunnel while it is running.

The engine exempts this app’s own SSH and certificate-fetch traffic to keep administration reachable. Other apps use the VPN. For protection while disconnected, enable Always-on VPN and Block connections without VPN in Android's VPN settings. Those settings may prevent managing a new server until you disconnect or adjust lockdown. Battery restrictions differ by phone; allow background VPN operation when Android asks.

Share access

Other users can install the official strongSwan Android app. Create their login, export the .sswan profile, and share the password separately through a trusted channel. The exported profile contains the public server certificate and login name; it does not contain the password.

Shared login: one login can have several simultaneous connections. Usage is combined, with individual sessions listed below it. Device login: give each device its own login under a person and name it Phone, Tablet or Laptop. This enables separate usage and revocation.

A device label identifies credentials or a profile. A copied profile can be used on another physical device. IP addresses and ports identify network endpoints; they change with mobile/Wi-Fi transitions and may be shared behind a router.

Connections and GB

Connection status is the server's most recent observation, not proof that a person is actively browsing. A lost device may remain listed until the VPN detects the loss. The app shows when it last refreshed.

Upload means data sent by a VPN user to the VPS; download means data sent from the VPS to the user. Usage is an operational estimate of tunnel traffic. It need not match your provider's bill, which also includes other services and protocol overhead.

Accounting starts when enabled. Existing sessions establish an initial baseline. Daily totals use UTC; detailed sessions are retained for 30 days and daily totals for about 13 months. Crashes or monitoring outages can leave gaps, which the app displays. Disabled accounting leaves live connections available but cannot recover missing past usage.

AdGuard strength

Standard uses the AdGuard DNS filter. Strong uses HaGeZi Pro. Strict uses HaGeZi Pro++ and is more likely to block a domain an app needs. Change one level at a time and compare if a website stops working.

DNS blocking cannot reliably remove YouTube in-video ads or ads delivered from the same domains as content. Apps with their own encrypted DNS may bypass the gateway's filter. The AdGuard dashboard stays on the private VPN network.

Check privacy and reachability

After connecting, check your visible public IP, DNS, and IPv6 from the actual phone on both Wi-Fi and mobile data. A country label can come from a location database, account region, cookies or GPS. A VPN does not change the reputation of its VPS IP address.

If a VPN fails before authentication, check UDP 500/4500 reachability. If only particular sites fail, distinguish DNS filtering, timeout and access-denied responses before changing protocols.

Credentials and updates

Saved administrator credentials are encrypted with Android Keystore when you select Remember. Otherwise they stay in this app session and you re-enter them next time. Backups are disabled. Losing the phone or clearing app data can require adding your server again.

Keep the APK, StrongSwan engine, SSH library and VPS packages updated. Preserve the release signing key when building your own APK; Android requires the same signer for an update.

Resetting a gateway

Reset gateway data reviews and permanently removes VPN users, certificates, AdGuard data, managed firewall rules and usage history from a recognized installation. Type DELETE VPN to confirm. Other clients lose access. Ubuntu, SSH and installed package binaries remain. A complete operating-system wipe/reinstall must be done using your hosting provider’s control panel. Unknown VPN configurations are refused. If SSH is unreachable, the app cannot perform a reset.
